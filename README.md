## Install & Run

Make sure you have Node.js 19.9.0 or higher installed.

Install dependencies:

``` bash
npm install
```

Start the development server:

``` bash
npm run dev
```

## Deployment

The project is configured for Cloudflare Pages deployment.

Deploy using:

``` bash
npm run deploy
```

You can also adapt the project for GitHub Pages if preferred.
